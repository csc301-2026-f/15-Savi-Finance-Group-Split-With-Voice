# Meeting Minutes

Add one Markdown file for each completed meeting, named `YYYY-MM-DD-partner-meeting.md`, `YYYY-MM-DD-team-meeting.md` or `YYYY-MM-DD-tutorial.md` as appropriate.

Use exactly this structure for every minutes file:

```markdown
# Meeting Type - Month Day, Year

- Time (Toronto): start–end
- Format: Online or In person
- Location: Online or physical location
- Partner: name

## Notes

- Record discussion points and decisions here.

## Action Items

- Owner: task and due date, if known.
```

For a tutorial, replace `Partner` with `TA`. For a team-only meeting, replace it with `Participants`. Use `Not recorded` for unknown time, format or location; a note timestamp does not establish the meeting time. Keep the four metadata bullets directly below the H1, in the order shown. Use only `## Notes` and `## Action Items` as H2 headings; put any topics or decisions under Notes. If no action items were recorded, write `None recorded.` Do not add notes-source or group-number fields.
